## Patch 3.0.3
## G-Macro
- Das Curses GW-Tool gibt es jetzt im Curses Launcher!
- Ihr könnt hier eure Sandbox oder Real GW Profile einstellen! Profil anlegen für eine Klasse, Macros einstellen. Profil unten links auswählen, dann auf "Starten" drücken & go!
## GuildLog
- Ihr könnt euren Guildlog jetzt im Tool hochladen!
- Im "data" ordner gibt es nun einen neuen Ordner namens "GuildLog". In diesem Ordner könnt ihr eure Logs platzieren und diese nachträglich auch über "Gespeicherte Logs" anzeigen lassen.
- Logs können ebenso per Drag & Drop oder per Klick über die Ordnersuche geöffnet werden. 
- Bei Fragen oder Ideen gerne melden im DC
## Fixes
- F-Loop erfolgt jeztt schneller (mindest Delay beim F-Loop ist nun auf 10ms einstellbar)
- Teleports wurden etwas angepasst: Beim ersten Teleportieren auf eine neue Map, kann es zu Problemen kommen, dass die Bar nicht zurückswitcht. Das liegt an den Flyff Client lags.
