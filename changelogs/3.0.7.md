# 3.0.7
## Features
- Ist ein Update verfügbar aber ihr grade im Dungeon? Im Tool oben findet ihr jetzt neben dem Minimieren das Curses Logo. Das blinkt auf sobald ein Update verfügbar ist & darüber könnt ihr es direkt installieren.
- Exen über das Programm starten. Ihr könnt nun in den Settings einmal eure .exe oder Verknpüfung auswählen, diese startet dann über den Button "Starten" die Anzahl an .exen die ihr eingestellt habt. Aktuell ist es bei DX11 nicht möglich problemlos alle exen zu starten. Viele schließen. Den Fehler muss Marvin beheben.
